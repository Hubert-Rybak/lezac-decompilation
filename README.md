# Lezac decompilation

Reverse-engineering workspace for **Larax & Zaco v1.0** (`LEZAC.EXE`),
using [REA](https://github.com/morluto/rea) with Ghidra's 16-bit real-mode loader.

The project keeps original game binaries and resources out of Git. Input hashes,
raw decompiler evidence, reconstructed routines, and differential tests are kept
separate so that generated pseudocode is never presented as a playable rebuild.

Initial repository setup. Analysis is developed on a separate branch and merged
after verification. See [RIGHTS.md](RIGHTS.md) for provenance and scope.
